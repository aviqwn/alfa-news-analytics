# Матрица 12 критериев успеха

Основа: оригинальный PDF, стр. 9–10. Проверки выполнены 22.10.2026. «Тестовый режим» означает собственные правила без LLM и не доказывает качество живой генерации.

| № | Требование | Реализация и проверка | Фактический статус |
|---|---|---|---|
| 1 | Бизнес-контекст конкретного клиента | Три профиля из CSV, происхождение полей, продукты/ФТС/группа/связи; два клиента одного ОКВЭД получают разные приоритеты | Работает в тестовом режиме, проверено offline и в браузере |
| 2 | Содержательная интерпретация нескольких факторов | Профиль + событие + роль + проверенный банковский фрагмент, условные механизмы и неизвестные | Правила реализованы; адаптер подготовлен. Живая модель и экспертная оценка ожидаются |
| 3 | Позиция банка отделена от AI | Отдельный блок, точная цитата, документ/страница/дата; только вручную проверенные актуальные фрагменты | 4 фрагмента сверены; 27 из 36 разборов содержат банковскую позицию. Полный OCR-корпус ещё не выверен |
| 4 | Объединение материалов и источники | RSS, ручной ввод, классификация, нормализация, дедупликация по заголовку/дате, evidence IDs | Импорт RSS и тест дублей пройдены; семантическое объединение разных публикаций не реализовано |
| 5 | Новые события | Общий pipeline для внешней и новой вручную введённой новости | Реальная публикация ЦБ и unseen-синтетика прошли анализ без изменения кода; экспертная устойчивость не измерена |
| 6 | Полный интерактивный сценарий | Главная → компания/роль → лента → разбор → вопрос → оценка | Браузерный сценарий пройден; 1440/768/390 px |
| 7 | Масштабирование и сопровождение | Модульные источники, версии данных, описаны очередь/БД/ACL/единый ledger | Описано в АРХИТЕКТУРА.md; многорепличное и нагрузочное исполнение не проверено |
| 8 | Метрики и мониторинг | Время, evidence coverage, банк, адаптация, токены/расход, отзывы; процесс экспертной проверки | API и отзывы проверены; технические измерения выполнены; экспертной метрики нет |
| 9 | Постоянная точка входа | Навигация «Пульс бизнеса» и блок главной | Проверено в браузере |
| 10 | Вопросы, другой разрез, первоисточник | parent_run_id, роль, связанные доказательства, локальные PDF | Follow-up/роль проверены; PDF доступны с номером страницы; реальный банковский SSO отсутствует |
| 11 | План, инструменты и адаптация | Собственный условный цикл, повтор поиска при пробеле/противоречии, ограничения | 9 из 36 случаев вызвали дополнительный поиск; конфликт/давность/пробелы покрыты тестами. Live-цепочка не проверена |
| 12 | Трассируемость действий и выводов | SQLite run state, инструменты, evidence IDs, признаки, проверки | Сохранение/чтение и валидность ссылок проверены; скрытые рассуждения не сохраняются |

Подробности — `reports/ПРОВЕРКИ.md`. Наличие источника не доказывает логическое следование вывода. Docker, GitHub и доступ жюри проверяются отдельно; на момент отчёта они ещё не закрыты.
