# Пульс бизнеса: описание проекта

## Задача и пользователь

Сервис помогает руководителю, финансовому директору и казначею понять, почему новость существенна для их компании. Он связывает событие с наблюдаемыми признаками компании, группой и доступными связями, вместо одного отраслевого пересказа для всех клиентов.

## Пользовательский сценарий

Постоянная точка входа в оболочке Альфа-Бизнеса → выбор компании и роли → персональная лента с объяснением значимости → разбор события → подтверждения и банковские цитаты → уточняющий вопрос или другой разрез → переход к источникам. Предусмотрены ввод нового события, обновление новостей из RSS ЦБ и оценка полезности.

## Собственная агентная логика

Приложение формирует план, получает профиль и связанные признаки, ищет новости и банковские фрагменты, связывает утверждения с источниками, сохраняет контекст, проверяет полноту доказательств и при недостатке/противоречии выполняет дополнительный поиск. Сохраняется трасса существенных инструментальных шагов. Готовая внешняя агентная система не используется. В режиме test вывод формируется собственной логикой, без вызова LLM; этот режим обозначен в интерфейсе.

## Данные и доказательства

Полный приватный репозиторий включает три CSV кейса, девять банковских PDF и подготовленные материалы. Для интерфейса выбраны три обезличенных профиля. Факты, позиция банка, условные выводы и неизвестные сведения разделены. Платёжные связи не объявляются собственностью, отсутствие признака не превращается в доказательство отсутствия обязательства. Для банковских цитат указываются документ и страница. Независимый синтетический сценарий доступен без банковских материалов и ключа.

## Техническая реализация

Основная версия: Python 3.12.14, стандартная библиотека, SQLite, HTML/CSS/JavaScript. Собственные компоненты поиска, ранжирования, агентной логики, памяти, кэша и учёта обращений к модели. Docker и единые команды запуска включены; зависимости и сторонние компоненты зафиксированы.

## AI и ограничения

Настроен адаптер OpenRouter для Gemma 4 26B A4B (`google/gemma-4-26b-a4b-it:free`). Последний короткий запрос 25.10.2026 получил HTTP 429. Успешная живая генерация и полный live-сценарий не подтверждены; автоматической смены модели нет. Допустимость своего провайдера и точного ID требует подтверждения организаторов. Ключ отсутствует в репозитории; расходы с неизвестными тарифами не выдаются за нулевые.

## Подтверждённые проверки и незавершённые пункты

26.10 повторно прошли 53 теста Python и синтетический сквозной сценарий. По проверке 25.10: Проверены 36 разборов с валидными ID-ссылками, 9 PDF по SHA-256 и загрузка 14 новостей ЦБ. Эти проверки не заменяют экспертную оценку рекомендаций.

Живой AI и Docker-запуск не подтверждены. Основной путь проверки для жюри - локальная Python-версия. Доступ аккаунта alfa-hack-2026 к приватному GitHub должен быть предоставлен отдельно.

## Запуск и проверка

После клонирования: `python3 scripts/run.py`, открыть http://127.0.0.1:8000 . Отдельный архив не нужен. Для независимой синтетики: `python3 scripts/demo.py`. Полная инструкция, Docker, конфигурация и порядок демонстрации находятся в README и submission/DEMO_SCRIPT.md.
